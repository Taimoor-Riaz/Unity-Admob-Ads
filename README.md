# Unity AdMob Ads

A drop-in AdMob ads manager for Unity with a custom editor script that handles multiple ad unit IDs.

## Features

- Single `AdsManager` component that you add to any GameObject
- Custom inspector for entering and managing multiple ad unit IDs
- Call ads from anywhere in your project through the manager

## Setup

1. Import the Google Mobile Ads SDK for Unity into your project.
2. Add this package to your project.
3. Add the `AdsManager` script to a GameObject in your first scene.
4. Enter your AdMob ad unit IDs in the inspector.
5. Call the manager from your scripts wherever you want to show an ad.
